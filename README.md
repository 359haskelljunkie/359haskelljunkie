### Why Haskell?

Because sometimes programming is more interesting when we stop asking:

> *"How do I make the computer do this?"*

and start asking:

> *"What exactly is this thing I'm trying to express?"*

Haskell encourages thinking in terms of:

* 🔹 Types
* 🔹 Functions
* 🔹 Composition
* 🔹 Immutability
* 🔹 Algebraic Data Types
* 🔹 Abstraction
* 🔹 Referential Transparency
* 🔹 Pure computation

For me, **Haskell is not only a tool for writing programs — it is a tool for learning how to think about programs.**

---

## 🟠 Category Theory

One of my strongest interests is **Category Theory**.

Category Theory gives programming another perspective: instead of looking only at individual implementations, we can reason about the **structures and relationships** between them.

I'm particularly interested in:

* 🧩 Categories
* ➡️ Morphisms
* 🔗 Composition
* 🎯 Functors
* 🔄 Natural Transformations
* 🌀 Monads
* 📐 Universal Properties
* 🧠 Abstraction and structure

And, perhaps most importantly:

> **How mathematical structures become visible through programming.**

Haskell is particularly fascinating in this respect because many concepts from Category Theory can be experienced directly through the language rather than remaining purely abstract mathematical definitions.
